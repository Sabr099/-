# Expense Tracker — Трекер расходов

Простое GUI-приложение для отслеживания личных расходов. 
Выполнено в качестве итоговой аттестации МЭО Академии.

Автор: Дзагаштов Мухаммад

## Функционал программы
* Добавление новых расходов (сумма, категория, дата).
* Отображение всех записей в таблице.
* Фильтрация расходов по категориям и по датам.
* Автоматический подсчет суммы расходов за выбранный период.
* Сохранение и загрузка данных через JSON-файл.
* Валидация ввода (сумма должна быть положительной, дата в правильном формате).
* Использование системы контроля версий Git + .gitignore.

## Как запустить программу

### 1. Подготовка
Убедитесь, что у вас установлен Python 3.

### 2. Создание виртуального окружения
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Mac/Linux:
source venv/bin/activate
### 3. Запуск
python expense_tracker.py
## Примеры использования
1. Введите сумму (например, 1000) в поле «Сумма».
2. Выберите категорию (например, «Транспорт»).
3. Нажмите кнопку "Добавить расход".
4. Проверьте обновление итоговой суммы в нижней части окна.
